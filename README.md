# LithoCMS

A self-hosted, AI-native CMS you install with one command and run with Claude.

- **Install and run** — one command on a VPS, automatic TLS, updates and backups.
- **Content and themes through MCP** — connect Claude to write posts or design a new theme;
  themes are validated Liquid templates and cannot run server code.
- **Many sites, one backend** — multi-site with strict tenant isolation.

> **Status:** early development. Not ready for production use.
